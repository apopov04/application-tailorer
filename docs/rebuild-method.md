# Rebuild method — 16 November 2026

Three independent Codex agents reviewed the existing skill: one used OpenAI’s skill-creator, one used Anthropic’s skill-creator, and one researched applicant/recruiter accounts. Each builder read the same published skill without the other proposal or evaluation outputs. This compares creator workflows, not OpenAI versus Claude model performance.

## Overlap and synthesis

Both builders recommended exact question/answer intake, independent selection of evidence and voice samples, purposeful example selection, coverage of every part of the new prompt, and specific editorial reasoning sized to the task. OpenAI added stronger prompt-coverage and story-selection checks. Anthropic made missing personal motivation more operational: ask a focused question while still producing supported partial progress.

The combined version adds employer/agency/client identity checks and an optional research-to-action step. It retains conflicting reports and distinguishes firsthand anecdotes from stated employer instructions. Seven discussion sources and two policy supplements are packaged with retrieval and confidence limits; one discussion has search-excerpt-only access. The deterministic length checker is unchanged.

## Behavioral comparison

The first comparison generated 16 outputs: four cases across published, OpenAI-only, Anthropic-only and combined versions. Cases covered initial intake, a capped company transfer with research commentary, resolved contradictory past claims and missing motivation, and a capped answer batch. All configurations had identical research access. One fresh-context runner per configuration completed four independent candidate scenarios sequentially. Fresh-context graders received anonymous A–D copies, the prompts and ledger, not the version mapping or proposals.

The published and two builder-specific versions passed 18/18 expectations. The first combined version passed 17/18: a batch answer added an unconfirmed causal result. Qualitative preferences varied by case. We tightened the distinction between actions, intended purpose and observed results, and clarified brief-note scope.

A second, fresh combined-versus-published comparison generated eight outputs over the same four cases. Both versions passed 18/18; anonymous graders judged all four cases ties. The final combined version is selected for the requested richer process and research integration, not a demonstrated universal quality advantage.

The name changed to Application Tailorer after the frozen writing runs. Final name, invocation, package links and metadata were validated separately. Structural validation passed, the checker remained byte-identical to the previously edge-tested version, and final answer caps were measured by executors and graders.

## Limits

This is a small qualitative regression comparison with one run per case, not repeated-trial statistics or hiring-outcome research. The second round reused case concepts, so it is not a held-out generalization test. No per-case token/duration data was exposed; none was invented. Applicant reports do not measure this skill’s effectiveness. Human feedback can still improve voice and usefulness after publication.
